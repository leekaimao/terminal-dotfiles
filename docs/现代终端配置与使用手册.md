# 现代终端配置与使用手册

> 适用环境：macOS + cmux + Ghostty 渲染层 + Zsh + Powerlevel10k<br>
> 当前记录日期：2026-08-27<br>
> 当前 cmux：`0.64.22 (102)`

这份手册记录当前机器上已经生效的终端配置、复现方式、日常用法、验证方法和回滚路径。所有示例都已移除密钥、令牌和内部凭证。

## 1. 当前方案一览

| 层级 | 组件 | 作用 | 当前风格 |
|---|---|---|---|
| 终端工作区 | cmux | 多窗格、标签页、Markdown 预览、任务管理 | 原生 cmux 界面 |
| 终端渲染 | Ghostty 配置 | 字体、颜色、透明度、光标、滚动历史 | Catppuccin Mocha |
| Shell | Zsh + Oh My Zsh | 命令解释、补全、插件 | 语法高亮 + 自动建议 |
| 提示符 | Powerlevel10k | 目录、Git 状态、环境、命令耗时 | 两行、信息精简 |
| 历史搜索 | Atuin | 模糊搜索历史命令 | 本地模式，不同步 |
| 文件管理 | Yazi | 三栏文件管理与预览 | Catppuccin Mocha |
| Git 界面 | Lazygit + Delta | Git TUI 与高亮 diff | 圆角 + Nerd Font |
| 系统监控 | btop | CPU、内存、网络、进程 | Catppuccin Mocha |
| 通用增强 | fzf、zoxide、eza、bat 等 | 搜索、跳转、列表、预览 | 同一配色体系 |

核心思路是：cmux 负责工作区，Ghostty 负责终端外观，Zsh/P10k 负责交互，Yazi/Lazygit/btop 负责高频任务。

## 5. cmux：让本地文件在 cmux 内打开

配置文件：`~/.config/cmux/cmux.json`

当前生效内容：

```jsonc
{
  "$schema": "https://raw.githubusercontent.com/manaflow-ai/cmux/main/web/data/cmux.schema.json",
  "schemaVersion": 1,

  "app": {
    "openSupportedFilesInCmux": true,
    "openMarkdownInCmuxViewer": true
  }
}
```

作用：

- `openSupportedFilesInCmux`：cmux 处理支持预览的本地文件。
- `openMarkdownInCmuxViewer`：Markdown 使用渲染后的 Viewer，而不是普通文本预览。
- 修改后按 `Cmd+Shift+,`，或者在 cmux 终端运行 `cmux reload-config`。

需要注意：在 Codex 聊天界面直接点击文件链接时，链接由 Codex 应用接管，不一定转交给 cmux。要确保在 cmux 中打开，使用：

```zsh
mdview /absolute/path/to/file.md
```

它实际调用：

```zsh
cmux markdown open /absolute/path/to/file.md
```

## 6. Ghostty：字体、透明度与主题

cmux 会优先读取 `~/.config/ghostty/config`。当前完整配置：

```ini
# Canonical Ghostty configuration used by cmux.
# The previous cmux-specific config is preserved in the terminal-config backup.

theme = Catppuccin Mocha
font-family = JetBrainsMono Nerd Font Mono
font-size = 14

cursor-style = bar
cursor-style-blink = true
mouse-hide-while-typing = true

background-opacity = 0.96
background-blur = 20
unfocused-split-opacity = 0.92
split-divider-color = #45475a

window-padding-x = 8
window-padding-y = 6
scrollback-limit = 50000000
```

参数说明：

- `JetBrainsMono Nerd Font Mono` 提供终端图标字形。
- `background-opacity = 0.96` 保留轻微透明感，同时保证文字可读性。
- `background-blur = 20` 让透明背景更干净。
- `unfocused-split-opacity = 0.92` 弱化未聚焦窗格。
- `scrollback-limit = 50000000` 保留更长的终端历史。

修改后按 `Cmd+Shift+,` 重新加载。若图标显示成方框，先在字体册中确认 Nerd Font 已安装，再检查 `font-family` 拼写。

## 7. Zsh 与 Powerlevel10k

### 7.1 Oh My Zsh 主配置

`.zshrc` 中与主题有关的关键内容：

```zsh
export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="powerlevel10k/powerlevel10k"

plugins=(git zsh-syntax-highlighting zsh-autosuggestions)

source "$ZSH/oh-my-zsh.sh"
[[ ! -f ~/.p10k.zsh ]] || source ~/.p10k.zsh
```

插件作用：

- `git`：常用 Git 别名和补全。
- `zsh-syntax-highlighting`：输入时标出命令是否有效。
- `zsh-autosuggestions`：根据历史命令显示灰色建议，按右方向键接受。

在 `~/.p10k.zsh` 中，左侧只保留目录和 Git，右侧显示必要状态：

## 8. `.zshrc`：现代工具初始化与别名

下面是当前终端增强配置。建议放在 Oh My Zsh 和 P10k 已加载之后、私密环境变量之前。

```zsh
export EDITOR="nvim"
export VISUAL="$EDITOR"

command -v zoxide >/dev/null && eval "$(zoxide init zsh)"
command -v fzf >/dev/null && source <(fzf --zsh)

export FZF_DEFAULT_COMMAND='fd --hidden --follow --type f --exclude .git'
export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND"
export FZF_ALT_C_COMMAND='fd --hidden --follow --type d --exclude .git'
export FZF_DEFAULT_OPTS='--height 45% --layout=reverse --border=rounded --info=inline --prompt="❯ " --pointer="◆" --marker="✓" --color=fg:#CDD6F4,bg:#1E1E2E,hl:#F38BA8,fg+:#CDD6F4,bg+:#313244,hl+:#F38BA8,info:#CBA6F7,prompt:#89B4FA,pointer:#F5E0DC,marker:#A6E3A1,spinner:#F5E0DC,header:#94E2D5,border:#6C7086'
export FZF_CTRL_T_OPTS="--preview 'bat --color=always --line-range :500 {}' --preview-window 'right,60%,border-left'"
export FZF_ALT_C_OPTS="--preview 'eza --tree --color=always --icons=always --level=2 {} | head -200' --preview-window 'right,60%,border-left'"

export BAT_THEME='Catppuccin Mocha'
command -v atuin >/dev/null && eval "$(atuin init zsh --disable-up-arrow --disable-ai)"

if command -v eza >/dev/null; then
  alias ls='eza --icons=auto --group-directories-first'
  alias ll='eza -lah --icons=auto --group-directories-first --git'
  alias la='eza -a --icons=auto --group-directories-first'
  alias tree='eza --tree --icons=auto --group-directories-first'
fi

if command -v bat >/dev/null; then
  alias preview='bat --paging=never'
fi

# Open Yazi and keep the directory selected when quitting with q.
y() {
  local yazi_tmp yazi_cwd
  yazi_tmp="$(mktemp -t 'yazi-cwd.XXXXXX')"
  command yazi "$@" --cwd-file="$yazi_tmp"
  IFS= read -r -d '' yazi_cwd < "$yazi_tmp"
  [[ -n "$yazi_cwd" && "$yazi_cwd" != "$PWD" && -d "$yazi_cwd" ]] && builtin cd -- "$yazi_cwd"
  command rm -f -- "$yazi_tmp"
}

command -v lazygit >/dev/null && alias lg='lazygit'
command -v fastfetch >/dev/null && alias ff='fastfetch'

# Open a Markdown file in cmux's rendered viewer.
mdview() {
  if (( $# != 1 )); then
    print -u2 'usage: mdview <markdown-file>'
    return 2
  fi
  cmux markdown open "$1"
}
```

修改后：

```zsh
zsh -n ~/.zshrc
exec zsh
```

## 9. fzf、zoxide、eza 与 bat

### fzf

- `Ctrl+R` 已让给 Atuin，用于历史搜索。
- `Ctrl+T` 搜索文件；右侧用 bat 显示语法高亮预览。
- `Alt+C` 搜索目录；右侧用 eza 展示两层目录树。
- 在结果列表中用方向键或 `Ctrl+J`、`Ctrl+K` 移动，按 `Enter` 接受，`Esc` 退出。

直接管道调用也很实用：

```zsh
rg -n 'TODO|FIXME' | fzf
git branch --all | fzf
```

### zoxide

```zsh
z project
z roll
zi
```

- `z 关键词`：跳到最常访问、名称匹配的目录。
- `zi`：通过 fzf 交互选择历史目录。
- zoxide 需要先访问一些目录，匹配结果才会越来越准。

### eza

```zsh
ls
ll
la
tree -L 2
```

`ll` 会同时显示隐藏文件、Git 状态、权限、大小和图标。

### bat

```zsh
preview README.md
bat --style=numbers --highlight-line 20 app.py
```

如果输出较长，直接运行 `bat FILE` 会自动使用分页器；`preview FILE` 不分页，更适合短文件。

## 10. Atuin：本地历史搜索

配置文件：`~/.config/atuin/config.toml`

```toml
# Local-only Atuin history. No account or sync service is configured.
auto_sync = false
update_check = false
search_mode = "fuzzy"
filter_mode = "workspace"
workspaces = true
style = "compact"
inline_height = 40
show_preview = true
secrets_filter = true
enter_accept = false
keymap_mode = "emacs"
store_failed = true
```

当前策略：

- 不登录账号，不启动同步，不上传历史命令。
- `Ctrl+R` 打开模糊搜索。
- 默认优先显示当前 Git 工作区中的历史。
- `Enter` 把命令放回输入行，不直接执行；确认无误后再按一次 `Enter`。
- `secrets_filter = true` 尝试过滤常见敏感命令，但它不是密钥管理器。
- 旧 Shell 历史没有自动导入，避免把历史中的敏感命令灌入数据库。

常用操作：

```text
Ctrl+R        打开历史搜索
输入关键词    模糊过滤
↑ / ↓         选择候选
Enter         放回命令行
Esc           退出
```

如果以后确实需要导入旧历史，先人工检查 `~/.zsh_history` 是否含令牌，再考虑 `atuin import auto`。不要未经检查直接导入。

## 11. Yazi：文件管理器

### 11.1 布局配置

`~/.config/yazi/yazi.toml`：

```toml
[mgr]
ratio = [1, 3, 4]
sort_by = "natural"
sort_sensitive = false
sort_reverse = false
sort_dir_first = true
linemode = "size"
show_hidden = false
show_symlink = true
scrolloff = 5

[preview]
wrap = "yes"
tab_size = 2
max_width = 1200
max_height = 1200
```

三栏比例是父目录 `1`、当前目录 `3`、预览区 `4`，让文件预览获得最大空间。

### 11.2 主题配置

`~/.config/yazi/theme.toml`：

```toml
[flavor]
dark = "catppuccin-mocha"
```

安装或更新官方主题包：

```zsh
ya pkg add yazi-rs/flavors:catppuccin-mocha
ya pkg upgrade
```

Yazi 会在 `~/.config/yazi/package.toml` 中锁定实际版本。当前机器已安装该主题。

### 11.3 日常使用

用 `y` 启动，不要直接用 `yazi`：

```zsh
y
```

| 按键 | 作用 |
|---|---|
| `h` / `j` / `k` / `l` | 上级目录 / 下移 / 上移 / 进入目录 |
| `Enter` 或 `o` | 打开文件 |
| `Space` | 选择或取消选择 |
| `y` | 复制所选文件 |
| `x` | 剪切所选文件 |
| `p` | 粘贴 |
| `d` | 移到废纸篓 |
| `z` | 通过 fzf 跳转 |
| `Z` | 通过 zoxide 跳转 |
| `Tab` | 查看文件信息 |
| `~` 或 `F1` | 帮助 |
| `q` | 退出，并让 Shell 进入当前目录 |
| `Q` | 退出，但不改变 Shell 目录 |

`d` 是可恢复的废纸篓操作；涉及永久删除时先看清目标，不要凭肌肉记忆确认。

## 13. Delta：更易读的 Git diff

当前 `~/.gitconfig` 中相关配置：

```gitconfig
[core]
    pager = delta
[interactive]
    diffFilter = delta --color-only
[delta]
    navigate = true
    line-numbers = true
    side-by-side = true
[merge]
    conflictStyle = zdiff3
```

无需额外命令，下面这些 Git 命令会自动经过 Delta：

```zsh
git diff
git show
git log -p
git blame FILE
```

- `n` / `N`：在 diff 文件之间前后跳转。
- `side-by-side = true`：左右对比，窄窗格下可能拥挤；可临时使用 `git -c delta.side-by-side=false diff`。
- `zdiff3`：冲突块同时显示共同祖先，便于理解双方改动。

## 16. 推荐工作流

### 进入项目并浏览

```zsh
z roll
ll
y
```

在 Yazi 中找到目标目录后按 `q`，Shell 会留在该目录。

### 查看和修改代码

```zsh
preview README.md
nvim src/main.py
rg -n 'TODO|FIXME' .
```

### 完成 Git 操作

```zsh
git diff
lg
```

先用 Delta 看精确 diff，再在 Lazygit 中选择性 stage、commit、push。

### 排查机器状态

```zsh
btop
dust .
procs python
```

在 cmux 中建议给 btop 单独一个较宽窗格；代码、日志和 Markdown 可以放在其他窗格。

### 找回以前的命令

按 `Ctrl+R`，输入项目名、命令片段或参数。Atuin 选中后只把命令放回输入行，先检查再执行。

前三个命令没有语法错误或 doctor 报错，才执行重新加载。

- `ll` 能显示 Nerd Font 图标。
- `Ctrl+T` 和 `Alt+C` 能打开 fzf 预览。

## 18. 常见问题

### 提示符或文件图标变成方框

原因通常是当前字体不是 Nerd Font。检查 Ghostty 配置：

```ini
font-family = JetBrainsMono Nerd Font Mono
```

确认字体已安装后，重新加载 cmux。

### 新配置只在部分窗格生效

旧窗格仍运行旧 Shell。每个需要更新的窗格执行：

```zsh
exec zsh
```

### btop 无法显示

将窗格拉宽到至少约 80 列，或新建一个独占大窗格再运行 `btop`。

### `lg` 提示不是 Git 仓库

先进入带 `.git` 的项目：

```zsh
git rev-parse --show-toplevel
```

该命令失败说明当前不在 Git 仓库。不要为了打开 Lazygit 随意执行 `git init`。

### Atuin 看不到旧命令

这是当前安全策略的预期行为：没有导入旧历史。继续日常使用后，新命令会逐渐积累。

### 点击 Markdown 仍在 Codex 中打开

Codex 应用里的链接由 Codex 处理。进入 cmux 终端执行：

```zsh
mdview /absolute/path/to/manual.md
```

### 在 Codex 自带终端直接调用 cmux CLI 被拒绝

部分 cmux 命令只允许从 cmux 自己的终端会话调用。切换到 cmux 窗格后运行同一命令即可。

## 19. 安全注意事项

1. 不要把 API Key、Access Key、Token 或密码直接写入 `.zshrc`、文档或 Git 仓库。
2. 当前 `.zshrc` 仍有历史遗留的明文凭证，本次终端美化没有修改它们。建议尽快轮换，并迁移到 macOS Keychain、企业密钥系统或可信密码管理器。
3. 可从 Keychain 读取占位凭证，但不要把真实值写进示例：

   ```zsh
   export EXAMPLE_API_KEY="$(security find-generic-password \
     -a "$USER" \
     -s 'example-api-key' \
     -w 2>/dev/null)"
   ```

4. Atuin 当前为本地模式；启用同步前先审计历史记录。
5. 备份目录可能包含旧环境变量和凭证，保持目录权限 `700`、文件权限 `600`，不要上传到云盘或 Git。
6. 如果密钥曾经出现在 Shell 历史、日志或聊天中，仅从配置里删除不够，还应在上游服务中撤销并重新签发。

## 20. 备份与回滚

本次改动前的备份目录：

```text
/Users/tbsg/.terminal-config-backups/20260827-204014
```

先查看备份内容和权限：

```zsh
ls -la /Users/tbsg/.terminal-config-backups/20260827-204014
```

以下命令会覆盖当前配置，只在确认需要完整回滚后逐条执行；不要整段盲目粘贴：

```zsh
cp /Users/tbsg/.terminal-config-backups/20260827-204014/.zshrc ~/.zshrc
cp /Users/tbsg/.terminal-config-backups/20260827-204014/.p10k.zsh ~/.p10k.zsh
cp /Users/tbsg/.terminal-config-backups/20260827-204014/config.ghostty ~/.config/ghostty/config
```

回滚后验证并加载：

```zsh
zsh -n ~/.zshrc
zsh -n ~/.p10k.zsh
exec zsh
```

然后在 cmux 中按 `Cmd+Shift+,`。

Atuin、Yazi、Lazygit 和 btop 是新增的独立配置，不影响 Shell 基本启动。若只想停用某个工具，优先注释 `.zshrc` 中对应初始化或别名，不要先删除程序和数据。
